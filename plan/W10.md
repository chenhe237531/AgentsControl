## 2. 三条产品约束（比组件库重要）

1. **今日页顶部只有 3 个数字 + 8 条决策卡 + 一句"今天到此为止"**。
   不加图表、不加列表、不加"更多"。首页每多一个元素，日均使用时间就多一分钟。
2. **默认只看异常**。执行页正常任务折叠成一行统计（"47 个正常 / 3 个卡住"），
   不做"全部任务列表"。
3. **项目视图不是"看着爽"，是发现三件事**：撞车（同文件被两个 Agent 改）、
   阻塞（等依赖/等审批超时）、偏离（改了无关文件）。三件事都必须可见且有颜色语义。

## 5. API 使用纪律

- **只通过 `web/src/lib/api/client.ts` 访问后端**，禁止在组件里 `fetch`。
- 类型来自 `npm run gen:api`（OpenAPI → TS）。后端未合并的端点在 `web/src/lib/api/types.ts` 里手工声明，
  并在注释里标 `// TODO(sync): W07-I01 合并后删除`。
- 4xx 不重试、5xx 自动重试（已在 `providers.tsx` 统一），页面不要各自写重试。
- 令牌**不放 localStorage**：访问令牌驻内存，刷新令牌走 httpOnly Cookie（`credentials: "include"` 已在 client 中设置）。
