## 2. 为什么用 Go 而不是 Python

单二进制、无运行时依赖、跨 Win/macOS/Linux、常驻内存 < 30 MB。
Python + PyInstaller 包体 50 MB+、杀软误报率高、Windows 上经常起不来——这是踩过坑的选择，
不要为了"和其它代码一个语言"改回去。

## 5. 本地验证命令

```bash
cd agent
gofmt -l .            # 必须为空
go vet ./...
go build ./...
go test ./... -race   # 并发相关改动必须跑 -race
AFC_API_BASE_URL=http://127.0.0.1:8000/api/v1 \
AFC_TOKEN=<测试 token> AFC_NODE_ID=n-test ./afc-agent
```

> 提示：沙箱里 `go build` 首次会因编译缓存很慢，可先 `GOCACHE=/tmp/gocache go build ./...` 预热。
